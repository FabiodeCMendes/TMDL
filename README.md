# O que é e o que faz o TMDL

O **TMDL** (*Tabular Model Definition Language*) é uma linguagem de modelagem baseada em texto criada pela Microsoft. Ela foi desenvolvida para definir, estruturar e gerenciar modelos de dados tabulares no Power BI e no Analysis Services. 

Sua principal função é transformar arquivos JSON complexos (como o antigo formato BIM) em uma estrutura de pastas e códigos limpa, legível por humanos e altamente otimizada para o desenvolvimento profissional.

---

### 📋 O que é o TMDL
* **Linguagem textual:** Sintaxe limpa baseada em recuos (indentações), fortemente inspirada no formato YAML.
* **Estrutura modular:** Divide o modelo semântico em múltiplos arquivos e pastas específicos para cada tabela, papel e cultura.
* **Representação do TOM:** Expõe de forma direta e amigável todas as propriedades do *Tabular Object Model*.
* **Padrão de mercado:** É o formato oficial da Microsoft para o desenvolvimento de BI focado em código (*Pro BI*).

---

### 🛠️ O que o TMDL faz
* **Facilita o Controle de Versão:** Torna o histórico de alterações no Git legível, permitindo rastrear mudanças linha por linha.
* **Evita Conflitos de Mesclagem:** Permite que múltiplos desenvolvedores trabalhem no mesmo modelo sem gerar erros complexos de *merge*.
* **Otimiza a Edição:** Permite alterar fórmulas DAX, renomear colunas e ajustar propriedades em lote usando editores de texto como o VS Code.
* **Automatiza Processos:** Viabiliza a criação de rotinas de CI/CD para testar, validar e implantar modelos automaticamente de forma segura.
* **Promove a Reutilização:** Facilita copiar tabelas inteiras, parâmetros e blocos de medidas de um projeto para outro instantaneamente.
